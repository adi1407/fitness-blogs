# SEO Playbook

## Architecture before articles

Rankings depend on URL hierarchy, clusters, internal links, tools, and page quality — not post volume.

## Intent types

| Intent | Example | Page type |
|--------|---------|-----------|
| Informational | What is creatine? | Article / guide |
| Calculation | How much protein? | Article + calculator |
| Comparison | Rice vs roti | Comparison article |
| Transactional | Best protein powder | Review (transparent) |
| Local | Gyms in Delhi | Only if we enter local SEO |

## Article UX template (required)

1. Breadcrumb  
2. H1 + author / updated / reading time  
3. Hero (optional)  
4. **Quick Answer** box + CTA to calculator when relevant  
5. Sticky **Table of Contents**  
6. Body with H2/H3 matching TOC  
7. Tables (requirements, foods)  
8. Embedded calculator when intent needs a number  
9. Indian / regional section when audience fits  
10. Key takeaways  
11. FAQ (real Qs only)  
12. Sources / references  
13. Author + reviewer boxes  
14. Related cluster links  
15. Newsletter  

## Metadata

Auto-generate title, description, canonical, OG/Twitter — editors can override.  
Prefer descriptive titles over stuffing.

## Structured data

Use only when accurate:

- Article / BreadcrumbList  
- FAQPage (only if real FAQ block + guidelines allow)  
- Recipe  
- Person / Organization / WebSite  
- SoftwareApplication for tools **only if applicable**

Never “add every schema.”

## Technical checklist

- XML sitemap (only valuable URLs)  
- robots.txt  
- Canonicals  
- Redirects (301)  
- 404  
- Semantic HTML  
- Image alt / sizes / AVIF-WebP  
- Mobile-first  
- Core Web Vitals (LCP, INP, CLS)  
- No thin auto-generated near-duplicates  

## Programmatic SEO

Food/exercise templates are allowed **if each page has unique useful content**.  
No 10k clone farms.

## Content freshness

Show Published + Updated only when truly reviewed.  
Track `lastFactCheckedAt` / `nextReviewDate` in CMS.

## Safety

Educational tone. No disease cures, medication-stopping advice, or miracle fat-burn claims.  
Prefer: calorie balance, training, lifestyle context + consult a professional.

## Competitive edge

Better answers · better UX · original Indian food data · calculators · exercises · evidence · EEAT · speed — not “more posts.”
